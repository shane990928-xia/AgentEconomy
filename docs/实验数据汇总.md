# 经济模拟平台 · 实验数据汇总

日期：2026-06-29

一句话：平台用**真实微观数据 + LLM 智能体决策**模拟宏观经济，验证经典经济规律（奥肯、菲利普斯）能否内生涌现，并用矩匹配对齐美国经验值。

> 阅读顺序：核心是第一节（LLM 决策结果）；后面几节是对照与可靠性验证；末尾附术语解释。

## 一、核心：LLM 决策结果

消费决策由 LLM 完成（每户每月读家庭画像 + 宏观处境做决策，monthly 全 LLM 模式），3 个随机种子。

**结论**：LLM 智能体驱动下，经典宏观规律仍然涌现，且经济正常运转。

### 1.1 LLM 经济的负相关规律（Okun + Phillips）
![llm regularities](figures/06_llm_regularities.png)

- Okun（失业↑→产出↓）、Phillips（失业↑→通胀↓）在 LLM 决策下均为负号，3/3 种子成立。

### 1.2 LLM 决策 vs 规则决策
![llm vs rules](figures/07_llm_vs_rules.png)

| 指标 | 规则 (n=5) | LLM (n=3, 逐seed) | 说明 |
|---|---|---|---|
| 失业波动率 (pp) | 2.93 | 3.44 / 2.50 / 2.91 | 基本不变 |
| Okun | −0.24 | −0.31 / −0.42 / −0.22 | 不变（3/3 负） |

| MPC | +0.19 | −0.04（均值） | LLM 下转负 |

- 失业波动率、Okun 在 LLM 层几乎不变；Phillips 保持负、略衰减；
- **MPC 由 +0.19 转 −0.04**：LLM 家庭消费更平滑、不机械跟当期收入，更接近真人。

## 四、稳健性验证

### 4.1 参数敏感性（证明涌现非调参）
改变劳动力囤积参数 `firm_layoff_speed`，看结论稳不稳。

| speed | 失业波动(pp) | Okun | Phillips |
|---|---|---|---|
| 0.20 | 2.62 | −0.45 | −0.09 |
| 0.35 | 2.99 | −0.30 | −0.14 |
| 0.50 | 2.88 | −0.16 | −0.41 |
| 0.75 | 3.24 | −0.25 | −0.18 |
| 1.00（关闭修复） | 5.55 | −0.20 | −0.06 |

- Okun、Phillips 在整个参数区间**全为负** → 符号稳健，非拟合到某个值；
- 失业波动率任意 speed<1 都稳定 ~2.6–3.2pp，只在关闭时（1.0）跳到 5.55。

## 七、术语解释

**三大宏观规律**
- **Okun 定律**：失业↑→产出↓（表中 corr(Δ失业, GDP增长)，负号=符合）。
- **Phillips 曲线**：失业↑→通胀↓（表中 corr(失业, 通胀)，负号=符合）。
- **Beveridge 曲线**：失业↑→空缺↓（表中 corr(失业, 空缺)，负号=符合）。

**校准 / 矩匹配**
- **矩**：对模拟数据算出的统计量（如失业波动率、基尼）。
- **矩匹配**：模拟的矩 vs 美国真实值比差距。
- **|z|**：`|模拟−目标|/容差`，越小越准；≤1.5 达标。
- **mean|z|**：所有计分矩的平均距离（1.57→1.00）。

**统计量**
- **AC(1) 持续性**：本期与上期相关性，高=有惯性，低=跳来跳去。
- **去趋势**：减掉长期趋势只留周期波动。
- **相对波动率**：某变量波动÷产出波动（消费应<1，投资应>1）。
- **基尼系数**：不平等度，0=平均，1=集中。
- **MPC（边际消费倾向）**：多赚 1 元里拿去消费的比例。
- **右偏**：分布长尾，少数大企业赚很多。

**实验设置**
- **regime**：一种模型配置（硬编码/工资竞价/校准经济）。
- **seed**：随机种子，多 seed 取均值±std。
- **rep**：同种子重复（并行有微小浮点噪声）。
- **n / (5/5)**：n=运行数；(5/5)=5 次里 5 次正确符号。
- **预热**：丢弃开头 12 月未稳定数据。
- **消融**：逐个关机制，看规律是否还在（判断真涌现 vs 硬造）。
- **敏感性扫描**：改一个参数看结论稳不稳。

**模型机制**
- **硬编码捷径**：用公式直接把失业写进工资/价格（非涌现）。
- **涌现**：规律从主体微观决策自发产生（平台核心主张）。
- **蛛网/周期-2 震荡**：就业每月高低交替跳（53/47），致失业波动虚高；已修复。
- **工资竞价**：企业招不到人自主加薪→真实工资成本价格传导。
- **LLM vs 规则模式**：决策由大模型做（读画像+处境）还是固定公式做。
- **三方 GDP 闭合**：三种算法结果一致（账目无漏）。
- **货币守恒**：总货币量不凭空增减。
- **企业进入/退出**：亏损破产退出，新企业进入同行业（熊彼特创造性破坏）。
