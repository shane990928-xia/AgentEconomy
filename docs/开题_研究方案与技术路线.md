# 经济模拟平台构建与验证 · 研究方案与技术路线

日期：2026-06-29
对应章节：第三部分「平台构建与验证」的研究方案与技术路线

---

## 一、研究目标

构建一个 **由 LLM 智能体决策、以真实微观数据为地基** 的宏观经济模拟平台，并通过
**正式的矩匹配校准 + 宏观典型事实涌现** 验证其合理性，为后续的机制研究（如轨迹抽取、
政策实验、LLM 替代劳动力等）提供可信的实验环境。

平台需同时满足两个层次的目标：
1. **构建目标**：主体、市场、数据、核算四要素完整且自洽（存量-流量一致，账目闭合）；
2. **验证目标**：模拟经济在正式矩匹配上对齐美国经验值，并内生涌现经典宏观规律
   （奥肯定律、菲利普斯曲线），且这些规律在规则与 LLM 双模式下均成立、对参数稳健
   （证明是涌现而非调参）。

---

## 二、数据基础（真实微观数据）

平台不使用抽象参数经济，而是以四类真实统计数据为地基：

| 数据源 | 内容 | 规模 | 在平台中的作用 |
|---|---|---|---|
| **PSID** 家庭面板 | 收入、净财富、支出、就业、教育、健康、债务、人格画像 | 家庭样本 + persona 映射 | 家庭主体初始化、消费经验锚、财富异质性、LLM 决策的 persona 输入 |
| **BLS / O\*NET** 职业 | 693 个职业的工资、技能、能力画像 | 693 职业行 | 劳动供给画像、招聘技能匹配、工资基准 |
| **BEA 投入产出表** | 71 个行业（20 制造 + 5 零售 + 41 服务/原料 + 5 政府）、直接消耗系数、V001 劳动报酬份额 | 71 行业 | 企业行业划分、供应链中间投入、劳动份额 |
| **Walmart 商品目录** | 真实商品名称、价格、品类 | 29,660 个 SKU | 商品市场 SKU、语义检索匹配目标 |

**技术路线要点**：数据在初始化阶段落地为主体属性与市场目录——PSID 行 → 家庭账户/画像；
O\*NET 职业 → 劳动小时画像；BEA 行业 → 企业与供应链结构；Walmart SKU → 可交易商品。
这保证了「家庭—工作—商品—行业」四张网都来自真实数据而非人工设定。

## 三、主体与环境构建

### 3.1 主体（Agents）

| 主体 | 类 | 职责 |
|---|---|---|
| 家庭 | `Household` | 消费决策（规则或 LLM）、劳动供给、储蓄 |
| 制造企业 | `ManufactureFirm` | 生产、中间品采购、招聘、定价 |
| 零售企业 | `RetailFirm` | 批发进货、零售、招聘 |
| 服务企业 | `ServiceFirm` | 服务供给、招聘 |
| 政府 | `Government` | 累进税、政府采购、公共就业、再分配 |
| 银行 | `Bank` + 信贷系统 | 家庭储蓄计息；企业信贷（内生货币） |

典型规模（校准配置）：50 家庭、66 企业、10 银行、1 政府，运行 60 个月（+3 月预热）。
（规模受 BEA 投入产出表锁定的 66 行业约束——每个行业至少一个企业以保持供应链完整。）

### 3.2 市场与核心（Environment）

| 环境 | 类 | 机制 |
|---|---|---|
| 劳动市场 | `LaborMarket` | 搜寻-匹配（技能损失摩擦）、工资竞价、部分调整裁员、公共就业 |
| 商品市场 | `ProductMarket` | 语义检索匹配（非瓦尔拉斯）、供需定价、零售/批发分层、库存 |
| 中间品采购 | `IntermediateGoodsProcurement` | 按 BEA 直接消耗系数的行业间投入 |
| 抽象资源市场 | `AbstractResourceMarket` | 服务类资源流转 |
| 经济中心 | `EconomicCenter` | 统一账本、双分录交易、信贷、税收、三方 GDP 核算 |

### 3.3 已实现的经济机制（模块清单）

- **劳动**：搜寻-匹配 + 技能损失、工资竞价（`firm_wage_bidding`）、劳动力囤积裁员
  （`firm_layoff_speed`）、公共就业、企业进入/退出（熊彼特创造性破坏）
- **生产**：EMA 需求预期 + 目标库存、产能约束（劳动/资本/现金）、中间品采购
- **金融**：企业信贷（内生货币双分录）、违约链、银行储蓄计息
- **财政货币**：累进所得税 / 企业税 / VAT / FICA、政府采购、Taylor 规则央行、利率传导
- **投资**：固定资本投资（实物资本品购买）+ 折旧

所有机制均 config 可开关，支持消融实验。

### 3.4 LLM 决策架构（平台核心创新）

平台的关键创新是 **「LLM 解读情境 + 经验数据锚约束」** 的混合决策架构，
有两个真实的 LLM 决策面：

- **家庭消费**（`consumption_llm_mode: monthly`）：每户每月三步 LLM 决策——
  大类预算分配（Step0）、品类需求描述（Step1，LLM 生成自然语言需求）、商品选择
  （Step3，LLM 选 SKU 并给理由）；每步都以经验规则消费计划为锚约束。
- **企业招聘**（`firm_job_posting_use_llm`）：LLM 对候选职业（SOC）给招聘优先权重，
  锚在全国职业分布上；岗位数/预算数学仍走规则，仅职业组合由 LLM 驱动。

**双模式基线**：`consumption_use_llm` 支持 off（纯规则）/ profile（LLM 缓存偏好画像）/
monthly（每月全 LLM）三档，构成内建的 **LLM-vs-规则对照基线**——这是研究「LLM 决策
带来什么差异」的方法论基础。

## 四、验证方法与验证了什么

### 4.1 存量-流量一致性（构建正确性）

平台的核算正确性由两个不变量保证，每月由核算诊断自动检查：

- **三方 GDP 恒等**：支出 = 生产 = 收入，`exp_vs_prod = 0.0`、`prod_vs_income ≈ 3e-11`（机器精度）
- **货币守恒**：总账现金不变（内生货币由企业债务对冲），漂移 ≈ 3e-8（相对）

两不变量在全功能开启（工资竞价 + 劳动力囤积 + 货币政策/固定投资 + 企业进入退出）下均成立。

### 4.2 宏观典型事实涌现（行为合理性）

**测量方法**：丢弃 12 月预热，对周期分量线性去趋势，在 0–3 阶滞后取最负相关，
5-seed grid 池化（工具 `tools/grid_table.py`）。

| 规律 | 定义 | 规则模式(5 seed) | 结论 |
|---|---|---|---|
| 奥肯定律 | corr(Δu, GDP增长) | −0.24，5/5 负 | 涌现（正确负号） |
| 菲利普斯曲线 | corr(u, 通胀) | −0.29，5/5 负 | 涌现（正确负号） |
| 贝弗里奇曲线 | corr(u, 空缺) | 正号 | 规模限制（见 4.5） |

**方法论关键**：菲利普斯经 **工资→成本→价格** 真实链涌现（企业空缺填不满→自主加薪→
真实工资帐单↑→单位成本↑→价格↑），非硬编码公式。用 `AGENTECO_COSTPUSH` 开关做消融实验
证明：去掉所有 reduced-form 捷径后底层传导仍给 ~−0.3 的菲利普斯，捷径只是放大器。

### 4.3 LLM 模式稳健性

3-seed monthly-LLM vs 5-seed 规则对比（工具 `tools/_compare_llm_rules.py`）：
奥肯（3/3 负）、失业波动率（2.89 vs 2.93pp）、财富/收入基尼在 LLM 层**不变**；
菲利普斯保持负但衰减，MPC 在 LLM 下由 +0.19 转 −0.04（LLM 家庭消费不机械跟当期收入，更像真人）。
→ 企业侧/财富结构结果 LLM-不变，消费传导是 LLM-敏感量——干净的 LLM-vs-规则发现。

### 4.4 参数稳健性（证明涌现非调参）

单参数扫描（工具 `tools/sensitivity_sweep.py`），以劳动力囤积 `firm_layoff_speed` 为例：
奥肯（−0.16…−0.45）与菲利普斯（−0.06…−0.41）在整个参数区间**保持负号**，
失业波动率对任意 speed<1 都稳定在 ~2.6–3.2pp，仅在关闭时（speed=1）跳到 5.55pp。
→ 规律的符号对参数稳健，是涌现而非拟合到某个点。

### 4.5 诚实的边界

贝弗里奇曲线在本规模不涌现负号（已穷尽 6 种机制验证）。诊断为**架构/规模限制**：
经济是劳动力过剩（劳动力≈59 / 岗位≈55 / 结构性失业≈11%），填补率恒≈95%，
空缺是残差而非独立存量；真贝弗里奇需要劳动力紧张的市场，这在 IO 锁定的 66 行业规模下
结构上不存在。作为规模限制诚实汇报，也指明了未来工作方向（更大/更紧的劳动市场）。

## 五、校准方法与技术路线

### 5.1 校准思路：修根因，而非拧参数

校准**不是**直接调参数去凑目标矩，而是**诊断并修复三个机制根因**，把矩匹配作为验证。
这是方法论上更强的做法（避免过拟合），三个根因修复：

1. **周期-2 劳动蛛网**（劳动力囤积 `firm_layoff_speed`）：企业每月把超预算员工一次裁到帽、
   次月需求回来再招回 → 就业交替震荡 → 失业波动率爆到 5.38pp。修复：渐进裁员（仅对持续
   超支逐步调整，只动裁员侧、保留招聘对需求的响应）→ 失业波动率 **5.38 → 2.93pp**。
2. **当期收入消费渠道**：在永久收入锚上叠加当期收入偏离项 → MPC **−0.32 → +0.19**。
3. **家庭财富异质性**：保留债务尾部 + 代表性抽样（小样本下横跨债务到富尾）→
   财富基尼 **0.39 → 0.72**，恢复 wealth>income 排序。

### 5.2 校准方法：矩匹配（SMM 风格）

工具 `tools/calibration_table.py`。技术路线：
1. 选取 9 个可对齐的经验矩（业务周期二阶矩 + 分布形状），设定美国经验目标值与容差；
2. 运行 5-seed grid，池化模拟矩（均值±std）；
3. 计算目标标准化距离 `|z| = |模拟 − 目标| / 容差`；
4. `|z| ≤ 1.5` 判为达标。

| 矩 | 模拟 | 美国目标 | \|z\| |
|---|---|---|---|
| 失业波动率 (pp) | 2.93 | 1.30 | 2.72 |
| 通胀持续性 AC(1) | −0.20 | 0.60 | 3.21 |
| 产出增长持续性 AC(1) | −0.47 | 0.30 | 2.56 |
| 消费相对波动率 (<1) | 0.91 | 0.60 | 1.24 |
| 投资相对波动率 (>1) | 1.28 | 3.00 | 1.15 |
| 企业收入右偏 | 3.15 | 2.50 | 0.43 |
| 收入基尼 | 0.42 | 0.39 | 0.47 |
| 财富基尼 | 0.72 | 0.85 | 1.29 |
| MPC | 0.19 | 0.40 | 1.04 |
| 失业水平 | 0.122 | 0.05 | (结构性，不计分) |
| 劳动份额 | 0.29 | 0.58 | (结构性，不计分) |

**校准结果**：**6/9 矩在 1.5 目标标准差内，mean |z| = 1.57**（修蛛网前为 2/9、mean|z| 2.04）。

### 5.3 校准的诚实性（可信度声明）

- **可信**：有正式距离度量（非仅报符号）、修根因而非拧参、参数稳健性 + LLM 稳健性双重验证、
  独立的核算闭合硬约束。
- **需补/需诚实报告**：经验目标值取自标准 RBC/劳动/不平等文献典型值（需逐条补引用来源）；
  容差为主观设定（|z| 绝对值有随意性，但相对排序稳定）；2 个矩（失业水平、劳动份额）
  作为小经济结构性偏离不计分；3 个矩（两个持续性 + 通胀 AC1）仍未达标，源于残余月度动态。
- **结论表述**：不宣称「校准完美」，而是「在小经济结构约束下达到 6/9 矩对齐，并诚实刻画偏离」。

## 六、技术实现要点

- **并行架构**：Ray actors（家庭/企业/市场/中心并行）；LLM 经 litellm 路由（异步并发）。
- **可复现性**：随机种子固定；因 Ray 并行浮点累加顺序，结果以多种子 mean±std 报告
  （并行 ABM 标准做法）。
- **工具链**：`calibration_table.py`（矩匹配）、`grid_table.py`（规律 grid）、
  `ablation_table.py`（消融分解）、`sensitivity_sweep.py`（参数稳健性）、
  `_compare_llm_rules.py`（LLM-vs-规则）、`paper_figures.py`（论文图）。
- **回归保护**：所有机制 config 门控，默认关闭时行为逐位不变；209 个单元测试全绿。

## 七、技术路线图（一页纸逻辑线）

```
真实数据地基 (PSID/BLS/BEA/Walmart)
        │
        ▼
主体构建 (家庭/企业/政府/银行) ── 环境构建 (劳动/商品/中间品/核算中心)
        │
        ▼
双决策模式 (规则 ↔ LLM，经验锚约束)
        │
        ▼
构建验证：三方GDP闭合 + 货币守恒 (机器精度)
        │
        ▼
校准：修三个根因 (蛛网/当期收入消费/财富异质) → 矩匹配 6/9, mean|z| 1.57
        │
        ▼
行为验证：奥肯/菲利普斯从真实传导涌现 (消融证明非硬编码)
        │
        ▼
稳健性：LLM 双模式 + 参数扫描全区间负号 (涌现非调参)
        │
        ▼
诚实边界：贝弗里奇规模限制 → 可信度 + 未来工作
```
